# Tip Calculator App

A responsive tip calculator built for the [Frontend Mentor challenge](https://www.frontendmentor.io/challenges/tip-calculator-app-ugJNGbJUX).

Enter a bill, choose a preset tip or type a custom percentage, and see the tip and total per person update instantly.

## Features

- Preset and custom tip percentages
- Tip and total calculated per person
- Clear selected state for preset tips
- Reset button to clear the calculator
- Responsive desktop and mobile layouts
- Keyboard navigation and visible focus states

## Built with

- HTML
- CSS Grid and Flexbox
- JavaScript

## Run locally

Open `index.html` in your browser. No installation is required.

## What I learned

This project helped me practice JavaScript input events, updating the DOM, calculating values from multiple form fields, and building responsive layouts with CSS.
